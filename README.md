# Articles of A New Republic

This repository is a draft constitution and a first set of statutes for a nation that does not yet exist. It is written as law, with the gaps marked, so the arguments stay concrete.

The nation is limited to protecting life and property and to the machinery that limit requires. Sub-jurisdictions may try thicker government — different taxes, services, and subsidies — and may not violate the national guarantees that make leaving real.

## Caveats

- Some choices are deliberate and still worth arguing. The commentary lists questions left open. The constitution itself is the enacted design of this draft, not a wish list.
- Voting, sortition, and the governance record are specified and not implemented.
- A pull request merged by a maintainer today edits the draft. It is not the enactment procedure in the legislature article.
