# Contributing to the Articles

This repository is a draft. A pull request merged here changes the draft. It does not enact law. Enactment, once a nation exists, is the process in [constitution/legislature.md](constitution/legislature.md): a frozen diff, a public review, and a ballot. The maintainer's merge button is not that ballot.

Discussion is welcome. Policy arguments belong in the discussion around a proposed edit, and the open questions in [commentary/open_questions.md](commentary/open_questions.md) are the unsettled ones.

## Where new text goes

- A national guarantee, a limit on power, or a change to how law is made goes in `constitution/`.
- An ordinary national rule, with a sunset, goes in `statutes/`.
- A note, an example, or an argument that should not be cited as law goes in `commentary/` and says so at the top.
- A pattern for local government goes in `sub-jurisdiction/`. Binding local rules are charters adopted by residents, not files added here by a maintainer.

A proposal in the future enactment process amends one file, states its authority, and stays within the word cap. Draft edits can be reviewed the same way even though they are not yet law.

## Technical aspects

Refer to [Markdown](http://daringfireball.net/projects/markdown/) for how to write markdown files.

Add images to the *images* folder if a file references an image.

Commentary is not law. Please do not put a binding rule only in a note.
